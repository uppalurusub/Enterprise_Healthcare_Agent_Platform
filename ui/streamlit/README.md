# 🏥 Enterprise Healthcare Agent Platform – Streamlit Frontend

A modern **Streamlit-based frontend** for the **Enterprise Healthcare Agent Platform**, providing an intuitive interface to interact with a FastAPI backend powered by **Microsoft AutoGen** multi-agent workflows.

The application enables healthcare professionals, researchers, administrators, and executives to submit complex patient cases and receive multidisciplinary recommendations generated by specialized AI agents.

---

# Features

* Modern Streamlit User Interface
* FastAPI REST API Integration
* Enterprise Healthcare Dashboard
* Clinical Case Submission
* Multi-Agent AI Workflow Execution
* Platform Health Monitoring
* Platform Information Dashboard

# Installation

## Clone Repository

```bash
git clone <repository-url>

cd streamlit_app
```

---

## Create Virtual Environment

### Windows

```bash
python -m venv venv

venv\Scripts\activate
```

### Linux / macOS

```bash
python -m venv venv

source venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# Configuration

Update the backend URL inside:

```text
utils/constants.py
```

Example

```python
BASE_URL = "http://localhost:8000/agents"
```

---

# Running the Backend

Start the FastAPI server.

Example

```bash
uvicorn main:app --reload
```

Default backend URL

```
http://localhost:8000
```

---

# Running the Streamlit Application

```bash
streamlit run app.py
```

Application URL

```
http://localhost:8501
```
